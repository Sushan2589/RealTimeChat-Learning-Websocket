# Learning WebSocket


This project of mine was a attempt of learning WebSocket where i read the docs of multiple places and expand my knowledge on WebSocket

This is a chat app that is real time 
For now it is just local where we can run the websocket server (server.js) and the express server (api.js)

Data is stored in data/db.json in plain text no hashing or anything and there is register and login for users 


Overall it was great being able to learn WebSocket and making a Real Time Chat App.
